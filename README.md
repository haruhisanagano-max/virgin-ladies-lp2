# 女性医療脱毛LP・最終調整版

## 開き方
全ページ確認には同梱の preview.html をブラウザで開いてください（画像内蔵）。編集・Xserver設置には index.html / style.css / config.js / links.js / script.js / assets を同じ配置で使用してください。
Googleマップの表示にはインターネット接続が必要です。

## 編集箇所
- config.js：文章、価格、FAQ、医院情報、画像パス。clinics の mapIframeUrl は埋め込み、mapPageUrl は別画面リンク用です。
- hero.image：TOP画像。imageFit は contain（全体を表示）、imagePosition は表示位置、imageRatio は表示領域の縦横比です。cover を選ぶと一部が切れます。
- reasons[].illustration：新規3点の透過イラスト。assets/images/reason-machine.png、reason-staff.png、reason-counseling.png を同名上書きできます。
- links.js：既存の予約・LINE関連設定。
- style.css：既存スタイルと末尾の最終調整スタイル。
- script.js：表示、院タブ、FAQ、レビュー、モーダル等。
